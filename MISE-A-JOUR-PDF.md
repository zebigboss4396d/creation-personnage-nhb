# Compatibilité des textes PDF

Le signe moins Unicode U+2212 est converti en tiret compatible WinAnsi dans tous les champs et les annexes. Les retours à la ligne des champs sont conservés. Les champs restent modifiables.

Remplacer fiche.js.

Vérification : génération des deux formats sur trois profils, avec et sans caractères Unicode dans le nom, les notes et les effets du matériel.
